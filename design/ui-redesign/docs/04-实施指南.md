# 04 · 实施指南（给写代码的 Agent）

> 目标：**把设计落到 `src/yqrec/ui/`，不改任何识别/录制/试听逻辑。**
> 全文按"可独立提交的 10 步"排列，每步都能单独出 `dist/YQRec/YQRec.exe` 给用户看。
> 遇到"要不要顺便重构"的念头时，答案永远是**不要**（见 §7 禁区）。

---

## 1. 交付物清单

| 文件 | 去处 | 说明 |
|---|---|---|
| `templates/theme.py` | `src/yqrec/ui/theme.py` | 令牌表 + `apply()` + 图标配色 + 下拉箭头生成 |
| `templates/qss.py` | `src/yqrec/ui/qss.py` | 唯一 QSS 模板（`{{token}}` 占位） |
| `tokens.json` | 不入代码，留在 `design/` | 机器可读令牌，给工具/其他 Agent 用 |
| `preview/index.html` | 不入代码 | 视觉基准，改完代码用它逐项比对 |

**不需要改**：`pyproject.toml`、`build/yqrec.spec`、`assets/*`。
QSS 是**内嵌在 `.py` 里的字符串**（不是 `.qss` 文件），所以**不用加 PyInstaller `datas`** ——
这是刻意的：打包漏一个 datas 条目就会出现"exe 里没样式"，排查成本极高。

---

## 2. 10 步落地顺序

> 顺序按"视觉收益 ÷ 逻辑风险"排。**每一步结束都跑一次 exe**，不要 10 步一起改完再跑。

| # | 步骤 | 动到的文件 | 风险 | 用户能看出什么 |
|---|---|---|---|---|
| 1 | 装主题基础设施 | +`theme.py` +`qss.py`，改 `_apply_theme()` | 极低 | 几乎无变化（配色微调） |
| 2 | 主题切换按钮 + 持久化 | `main_window.py` | 低 | 右上角日/夜切换，重启记住 |
| 3 | 区块卡 + 区块头 | `main_window.py::_build_ui` | 低 | 三段变成三张卡，标题更干净 |
| 4 | 键位卡改属性驱动 | `keys_panel.py` | 低 | 卡变矮变清爽，Δ 会变琥珀预警 |
| 5 | 工具栏：文案 + 档位 + 主操作迁移 | `main_window.py` | 中 | 按钮有了主次，一行只有一个蓝按钮 |
| 6 | 试听胶囊 | `main_window.py` | 低 | 控制条合成一个胶囊 |
| 7 | 状态栏重构 | `main_window.py` | 中 | 徽标 + 单条消息，不再两处跳 |
| 8 | 编辑浮层：投影/箭头/分段 | `main_window.py` | 中 | 真像浮层了 |

```python
def _apply_theme(self, name: str | None = None) -> None:
    """套用主题：颜色全部来自 theme.py 的令牌，这里不再出现任何 #hex。"""
    self._theme = theme.apply(self, name or theme.current())
    self._config.ui.theme = self._theme
    self._repaint_theme_dependents()

def _repaint_theme_dependents(self) -> None:
    """QSS 管不到的绘制层要手动通知（图标 / 键位卡状态 / 预览叠加色）。"""
    self._keys_panel.refresh_style()
    self._preview.refresh_theme()
    self._btn_ontop.setIcon(pin_icon(self._btn_ontop.isChecked(),
                                     colors=theme.media_colors()))
    self._btn_toggle_play.setIcon(media_icon("pause", colors=theme.media_colors()))
    self._btn_rewind.setIcon(media_icon("rewind", colors=theme.media_colors()))
    self._btn_forward.setIcon(media_icon("forward", colors=theme.media_colors()))

```

### 3.3 步骤 3 · 区块卡 + 区块头

在 `_build_ui()` 里，键位/预览/录制三段各包一层 `QFrame#SectionCard`：

```python
def _make_section(self, title: str, meta: str = "") -> tuple[QFrame, QVBoxLayout, QLabel]:
    """一张区块卡：header（标题 + 右侧 meta）+ 内容容器。

    返回 (卡片, 内容布局, meta 标签)；调用方把真正的控件塞进内容布局。
    """
    card = QFrame(self)
    card.setObjectName("SectionCard")
    outer = QVBoxLayout(card)
    outer.setContentsMargins(0, 0, 0, 0)
    outer.setSpacing(0)

    header = QWidget(card)
    header.setObjectName("SectionHeader")
    header.setFixedHeight(28)
    row = QHBoxLayout(header)
    row.setContentsMargins(10, 0, 10, 0)
    row.setSpacing(8)
    label = QLabel(title, header)
    label.setObjectName("SectionTitle")
    meta_label = QLabel(meta, header)
    meta_label.setObjectName("SectionMeta")
    row.addWidget(label)
    row.addStretch(1)
    row.addWidget(meta_label)

    body = QWidget(card)
    body_layout = QVBoxLayout(body)
    body_layout.setContentsMargins(0, 0, 0, 0)
    body_layout.setSpacing(0)

    outer.addWidget(header)
    outer.addWidget(body, 1)
    return card, body_layout, meta_label
```

要点：
- 标题**不再用行内 `setStyleSheet`**（现在两处 `keys_title` / `record_title` 是硬编码 `color:#8fa0b3`，删掉）。
- 预览卡的内容布局 `contentsMargins(0,0,0,0)`（画面自己留 8）。
- `splitter.setSizes([246, 330, 200])`，`setStretchFactor` 保持 0/1/0。

箭头：`panel` 用 `paintEvent` 画（需要给 `QFrame` 装一个子类，或在 `MainWindow` 里不好画）。
最省事的方式：定义一个 6 行的 `EditPanel(QFrame)` 子类，`paintEvent` 里画三角：

```python
class EditPanel(QFrame):
    """浮层容器：自己画一个指向触发按钮的小三角（12×8）。

    QSS 画不了三角，只能用 QPainterPath；箭头水平位置由外部通过 arrow_x 指定。
    """
    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self.setObjectName("EditPanel")
        self.arrow_x = 72       # 相对面板左边；-1 = 不画

    def paintEvent(self, event) -> None:
        super().paintEvent(event)
        if self.arrow_x < 0:
            return
        painter = QPainter(self)
        painter.setRenderHint(QPainter.RenderHint.Antialiasing, True)
        path = QPainterPath()
        x = max(12, min(self.arrow_x, self.width() - 12))
        path.moveTo(x - 7, 1)
        path.lineTo(x, -6)          # 画到面板外（上方），需给子控件留出 y 空间
        path.lineTo(x + 7, 1)
        painter.setBrush(theme.color("bg-elevated"))
        painter.setPen(QPen(theme.color("border-default"), 1))
        painter.drawPath(path)
```
> 三角形画在面板**上边缘之外**，`panel.move()` 时要预留 8px（`y -= 8`），否则被裁掉。
> 若嫌麻烦，**第一版可以只做投影不做箭头** —— 投影已经解决了 80% 的"不像浮层"问题。

## 8. Qt QSS 踩坑速查（这几个坑一定会遇到）

| 现象 | 原因 | 解法 |
|---|---|---|
| 改了 `setProperty` 但样式没变 | Qt 不监听 property 变化 | `unpolish + polish`（用 `theme.set_state()` / `theme.repolish()`） |
| 按钮获得焦点时整体跳 1px | `:focus` 里改了 `border-width` | 只改 `border-color`（本模板已遵守） |
| 子控件的 QSS 不生效 | 父控件设了 `setStyleSheet` 后子控件继承受限 | 全局样式只在 `QMainWindow` 上设一次 |
| `QComboBox` 下拉列表还是系统灰白 | 忘了 `QComboBox QAbstractItemView` | 模板已包含 |
| 下拉箭头变成方块/消失 | `image: url()` 路径含反斜杠或文件不存在 | `theme.chevron_url()` 返回 `file://` URI（已处理） |
| 圆角不生效 | 控件没有背景色 | 先给 `background`，再给 `border-radius` |
| 日间主题下白字看不见 | 某处仍硬编码浅色 | 搜 `#` 与 `QColor(`，全部令牌化 |
| 打包后没样式 | QSS 用了外部 `.qss` 文件但没加 `datas` | **本方案把 QSS 内嵌在 `.py`**，天然没有这个问题 |
