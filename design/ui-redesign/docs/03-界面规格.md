> 加 1px `border-subtle` + 8px 圆角，浅色下结构立刻清楚，深色下几乎不可见（不增加噪音）。

### 1.6 主操作迁移（唯一的行为级视觉逻辑）

新增 `MainWindow._refresh_action_emphasis()`，在 `_toggle_preview` / `_toggle_record` /
`_learn_baseline` 结束处各调一次（或用 `QTimer.singleShot(0, ...)` 兜底）。

```python
def _refresh_action_emphasis(self) -> None:
    """一行只允许一个 accent 填充按钮：让"下一步"永远只有一个。"""
    previewing = self._worker is not None
    recording = self._recording
    has_baseline = self._baseline is not None

    # 试听中：主操作在控制条里（播放/暂停），工具栏整体降级 —— 否则"开始预览"会骗人去点
    if self._play_mode:
        for button in (self._btn_record, self._btn_preview, self._btn_baseline):
            _set_role(button, "Secondary")
        return
    # 录制态：两个"停止"都是收尾动作 → 都 danger（tonal）；此时没有 L0
    if recording:
        _set_role(self._btn_record, "Danger")      # 停止录制
        _set_role(self._btn_preview, "Danger")     # 停止预览（会一并收尾录制）
        _set_role(self._btn_baseline, "Quiet")
    # 预览中且已学基线：录制成为主操作，停止预览是收尾
    elif previewing and has_baseline:
        _set_role(self._btn_record, "Primary")
        _set_role(self._btn_preview, "Danger")
        _set_role(self._btn_baseline, "Secondary")
    # 预览中但没基线：学习基线是主操作，停止预览仍是收尾
    elif previewing:
        _set_role(self._btn_record, "Secondary")
        _set_role(self._btn_preview, "Danger")
        _set_role(self._btn_baseline, "Primary")
    # 静止态：预览是唯一能推进的动作
    else:
        _set_role(self._btn_record, "Secondary")
        _set_role(self._btn_preview, "Primary")
        _set_role(self._btn_baseline, "Secondary")

def _set_role(button, role: str) -> None:
    """换 objectName 并重算样式（QSS 用 objectName 挂钩，见 04 §3.4）。"""
    if button.objectName() == role:
        return
    button.setObjectName(role)
    theme.repolish(button)
```

> 规则只有两条：**`Primary`（accent 实心）一屏最多一个**；**`Danger`（tonal 红）只给"停止 X"**。
> 录制中允许两个 `Danger` 并列（都是收尾），靠位置区分：预览在左、录制在右。
> 禁用态由 QSS 的 `:disabled` 兜住，**不参与层级判断**（禁用的按钮视觉上已退到最底）。
>
> 为什么 danger 不做实心：见 `01-设计规范.md` §3.2 —— 两块实心红会把 L0 盖掉，
> 而且"实心=推进"这条语法要保持唯一。

### 2.3 Δ 提前预警（本次唯一的新视觉信息）

```
ratio = delta_score / max(1, threshold.delta)
ratio ≥ 0.60 且未按下  →  QLabel#KeyDelta[tone="near"]  → 颜色 warn
否则                   →  移除 tone 属性            →  颜色 text-tertiary
```
目的：让用户**看见"差一点"**。调 Δ 时不用再盯着数值心算，接近阈值的那一格先变琥珀。

> 阈值 60% 是经验值：低于 60% 噪声太多（正常抖动 10~25%），高于 80% 会一直闪。
> 数据来源：`assets/instruments.json` 各乐器 Δ（30~40），`keys_panel` 里已有 `KeyThreshold.delta`。

### 2.4 三种状态

| 状态 | `state` 属性 | 底 | 边 | 文字 |
|---|---|---|---|---|
| 未标定 | `disabled` | 透明 | 1px **虚线** `border-default` | `text-disabled` |
| 空闲 | `idle` | `bg-surface` | 1px 实线 `border-subtle` | 三级（见 §2.2） |
| 按下 | `pressed` | `success` | 1px `success` | `success-fg`（整卡反色） |

> **按下态不放投影、不放光环**。扁平风格里"整卡变绿"本身就是最强信号；
> 加发光会让 21 张卡同时按下时变成一团糊。日间主题同样是绿底深字 —— 跨主题保持识别一致。

### 2.5 空态 / 换乐器

- `SectionMeta` 在未标定时显示 `未标定`（替代 `7×3 · 21 键`）。


| 消息 | `Toast` | 11px | 语气色 | 见 §6.3 |

### 6.2 宽度优先级（替代原来的一行 5 段）

按可用宽度逐级丢弃，**永远保留徽标与 FPS**：

| 宽度 | 显示 |
|---|---|
| ≥ 620 | `59.8 fps · 源 59.9 · 单帧 0.6ms · 512 帧` |
| 560~619 | `59.8 fps · 512 帧` |
| < 560 | `59.8 fps` |
| 等待新帧 | `等待新帧… · 512 帧`（保留帧数，因为它在涨，能证明活着） |

> 判断放 `resizeEvent` 里算一次，存成 `self._status_compact`；`_update_status()` 按它拼文案。
> **不要**每帧重算宽度（`width()` 便宜，但每帧拼 4 种字符串没必要）。

### 6.3 统一消息区（修 §9 第 5 条）

原实现有两套：`statusBar().showMessage()`（左下）与 `_lbl_error`（右下红字），位置会跳。

新实现：**只留 `QLabel#Toast`**，一个方法两个语气：

```python
def _toast(self, message: str, tone: str = "info") -> None:
    """tone: info | warn | error。4 秒后自动淡出（直接清空，不做动画）。"""
    self._lbl_toast.setProperty("tone", tone)
    theme.repolish(self._lbl_toast)
    self._lbl_toast.setText(message)
    ...  # 复用现有 _error_timer，超时 setText("")
```
- `_flash_status(msg)` → `_toast(msg, "info")`
- `_set_error(msg)` → `_toast(msg, "error")`
- 回退/低帧率提示 → `_toast(msg, "warn")`
- `setMaximumWidth(260)` + `elide`：长消息截断，完整内容进 tooltip。

## 8. 可用性矩阵（视觉表现 · 逻辑不变）

逻辑沿用 `docs/04-UI界面说明.md` §6。这里只规定**禁用态的视觉**：

| 控件类 | 禁用表现 |
|---|---|
| `Secondary` / `Quiet` / `Toggle` | 底 `bg-surface`（Quiet 为透明）、边 `border-subtle`、字 `text-disabled` |
| `Primary` | **退回 Secondary 的样子**（不留 accent 残影，避免"看起来能点"） |
| `Danger` | 同 Secondary 禁用态 |
| 下拉 | 底 `bg-surface`、边 `border-subtle`、字 `text-disabled` |
| 滑条 | 已填充段 `text-disabled`、手柄 `text-disabled` |
| 键位卡 | `state="disabled"`（虚线） |

> 关键：**禁用 ≠ 变淡**。禁用是"换一套更弱的配方"，不是给正常态加 40% 透明度 ——
> 后者在浅色主题下会糊成一片灰，看不清文字。
