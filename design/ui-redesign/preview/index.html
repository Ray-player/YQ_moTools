这一版改了什么

  • 层级：按钮分四档（主 / 常用 / 工具 / 收尾）。工具栏任意时刻只有一个蓝色实心按钮，且它会随运行态迁移（开始预览 → 录制谱面 → 停止录制）。
  • 结构：三段变成三张卡（bg-panel + 1px 细边 + 8px 圆角），夜间几乎看不出边框，日间立刻分明。
  • 减噪：去掉「后端 / 乐器 / 检测 / 半径」四个文字标签、缩短六处按钮文案，挤出的宽度全给了半径滑条。
  • 键位卡：矮 4px、字号固定 px、Δ 接近阈值时变琥珀 —— 调 Δ 时不用心算。
  • 试听：四个按钮收成一个胶囊，图标 16→18px。
  • 状态栏：拆成「后端徽标 + FPS + 次要数值」，一次性提示与错误合并到右侧同一条消息位上。
  • 二级面板：手动点选浮层贴住触发按钮右下方（右对齐按钮右缘）、箭头指向按钮中心，被触发按钮自身高亮；点画面空白处等同「保存退出」。切到「手动点选」态可看实际位置。

双主题怎么保证不走样

  • 一份 QSS 模板 + 两张令牌表。切换只换变量，几何（圆角/间距/字号）同源，所以不会出现"夜里有圆角、日间变直角"。
  • 日间不是夜间反色：底色用冷白灰 #F4F6F8（不用纯白），强调色压深一档保证 4.5:1。
  • 检测圈 / 采样点 / 按下高亮 不跟主题 —— 它们压在游戏画面上，游戏画面亮度与 App 主题无关。
