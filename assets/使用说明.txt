========================================
 YQ_moTools 使用说明
========================================

【这是什么】
把游戏（或视频）里的演奏界面"看"下来，实时判断你按了哪些琴键，
再录成谱面文件；也能读取、编辑、试听别人做的谱面。

【第一次使用：6 步】
1) 双击 YQ_moTools.exe。窗口默认置顶，贴着游戏放就行（拖边缘可改大小，会自动记住）。
2) 点「框选区域」，在屏幕上拖出一个方框 —— 只框住琴键区域（一般 7×3 共 21 个键）。
   框错了就再点一次重新框。
3) 在「乐器」下拉里选你用的乐器（默认「风物之诗」）。
   下拉里带「· 仅预览」且灰显的乐器（目前是悠可琴 / 余音）暂时选不了：
   它们的识别参数还在标定中，选进去会认不准，先占位让你看到支持列表。
   等标定完成会放开（届时重开程序即可）。
4) 点「自动检测」—— 程序会在框内找出 21 个琴键并画圈。
   有漏检或画歪：点「手动点选」，用「拖动 / 新增 / 删除」调好，再点「保存退出」。
5) 点「开始预览」—— 上方画面开始实时刷新，圈里的数字就是它认的键位。
6) ★先松开所有琴键★，再点「学习基线」，保持 1.5 秒不要按任何键。
   这一步在记"没按键时每个键的颜色"，之后靠颜色变深判断按下。
   如果学的时候正好按着某个键，那个键以后会一直判不出来。

【录一首曲子】
7) 点「录制谱面」→ 回游戏里正常弹 → 弹完点「停止录制」。
8) 下方文本框里就是谱面，可以直接手动修改。
9) 选好格式后点「保存」：
   · tick（默认）：本软件自己的格式
   · BGI · midi / BGI · yuanqin：给 BetterGI、五线谱制谱器用
10) 点「试听」听效果（需先「停止预览」）。暂停后可用 ⏪ ⏩ 定位。

【什么时候要重新标定】
· 换乐器 → 重新「自动检测」+「学习基线」（换过的乐器会被记住，下次启动还是它；
  但它的标定要重新做一遍 —— 别的乐器的键位/基线不会套过来）
· 改了游戏分辨率 / 窗口大小 / 界面缩放 → 重新「框选区域」+「自动检测」
· 改过识别参数里的采样半径 → 重新「学习基线」

【识别不灵怎么办】
· 灯完全不亮：先确认学过基线；再确认学基线时是"全部松开"的状态。
· 偶尔漏一个音：把该乐器的 delta 调小（默认 20，越小越灵敏，可试 15）。
  位置：程序目录\_internal\assets\instruments.json，改完按 F5 重读。
· 一直误报（没按也亮）：把 delta 调大一点（25~30），或重新学基线。
· 帧率低：右上角「后端」保持 dxgi；数值仍低说明游戏画面本身只有那么多帧。
· 开了 HDR（Windows「设置 → 系统 → 显示 → 使用 HDR」）后画面发白、灯不亮：
  「后端」保持默认的 j-HDR 即可 —— 它按显示器的 SDR 白电平重新换算颜色。
  如果 j-HDR 打不开（状态栏显示「回退」），程序会自动退到 dxgi，此时建议先关掉系统 HDR。
  切换 HDR 开关（或换了 j-HDR / 换回 dxgi）都会改变取到的颜色，
  ★务必重新「学习基线」★，否则拿旧基线去比会一直判错。

【界面速查】
· 右上角图钉 = 窗口置顶开关（默认开）
· 右上角月亮 / 太阳 = 日间 / 夜间主题
· 右上角「后端」= j-HDR（默认）/ dxgi / gdi（兜底）；选过就会被记住，下次打开沿用
· 底部状态栏 = 抓帧后端、帧率，以及操作提示（提示和报错都在这里）
· F5 = 重新读取识别参数

【延音（谐律键琴这类乐器）】
· 乐器是否延音由乐器的 sustain_ms 决定（0 = 不延音；大于 0 = 按住够久才算延音）。
  谐律键琴 = 300 毫秒：按住不到 300ms 当作普通一击，不记延音。
· 按住够久时，谱面里会写成 A[800] 这样 —— 方括号里是按住多少毫秒。
· 录到一半松开手也没关系：点「停止录制」时，还按着的键会按"已经按了多久"记延音。
· 文字谱可以直接手改方括号里的数字；导出 BGI 时它会变成抬键的时刻。
  注意：BGI · yuanqin 是"音符时值"格式，而且是一个音接一个音顺序播放的 ——
  "一个键还按着、另一个键就响"这种叠音它表达不了，长音会被下一个音的起点截断。
  保存后状态栏会如实告诉你"有几处延音被截短、最长多少毫秒"。
  ★要完整保留延音（尤其是按住一个键还弹别的键）请导出 tick 或 BGI · midi★；
  BGI · midi 是逐键"按下/抬起"事件，叠音和延音都不丢。
· 想改阈值：assets\instruments.json（打包后在 _internal\assets\ 下）里该乐器的 "sustain_ms"，改完按 F5。
· 想更"严格"地确认按下：detection.confirm_frames（默认 2 = 连续两帧都亮才算按下；
  改成 1 = 看到就认，但动画闪一下也可能被当成按下）。

【文件位置】
· 设置与标定：%APPDATA%\YQ_moTools\
· 默认谱面目录：文档\YQ_moTools\
· 识别参数：程序目录\_internal\assets\instruments.json

【弹出「存档目录写入异常」怎么办】
程序每次启动都会试着往存档目录写一个测试文件。写不进去时会弹窗告诉你原因，并
临时改用程序目录下的 data\ 文件夹（设置、标定、日志都写在那里，功能完全正常，
就是换了个位置存）。想让它回到 %APPDATA%\YQ_moTools：
  1) 把 %APPDATA%\YQ_moTools 和程序目录加进安全软件（360 等）白名单；
  2) 或者直接删掉 %APPDATA%\YQ_moTools 整个文件夹，再重新打开程序（要重新标定一次）。
